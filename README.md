# DormNet

## Wi-Fi Monitoring and Accessibility Mapping System for Pisay Dormitories

DormNet is a project designed to organize,
analyze, and visualize Wi-Fi performance measurements collected
from different locations in PSHS-BRC's dormitories.

## Problem

Wi-Fi performance can differ depending on location, time, and other
environmental factors. DormNet has objectives to help identify areas with weak or inconsistent Wi-Fi performance through structured
data collection and summarization.

## Planned Features

- Wi-Fi measurement recording
- Data organization
- Wi-Fi performance analysis
- Location comparison
- Time-based analysis
- Wi-Fi accessibility mapping
- Reports

## Inputs

- Location
- Date and time
- Signal strength
- Download speed
- Upload speed
  - 

## Outputs

- Wi-Fi performance classification
- Statistical summaries
- Location comparisons
- Accessibility map
